# 细胞内部漫游 · Inside the Cell

高中生物 **必修1 第3章《细胞的基本结构》** 的可交互 3D 细胞模型。

> 本版本的界面与交互优化由 [OrbitPy](https://github.com/OrbitPy) 完成，感谢其贡献。

## 在线打开

- **入口页**：https://tim261004.github.io/cell/
- **桌面版**：https://tim261004.github.io/cell/desktop.html
- **手机版**：https://tim261004.github.io/cell/mobile.html

建议电脑使用桌面版，手机使用手机版。两个版本内容一致，布局和操作方式不同。

## 内容

- 动物细胞 / 植物细胞切换
- 15 类细胞结构：细胞膜、细胞质基质、细胞核、线粒体、叶绿体、内质网、高尔基体、核糖体、溶酶体、中心体、液泡、细胞壁、细胞骨架、囊泡、过氧化物酶体
- 8 种胞内物质：水、无机盐、糖类、脂质、蛋白质、核酸、ATP、酶
- 每个条目包含：结构速览、组成与结构、主要功能、考点提醒、相关结构
- 本章速记：膜层分类、分泌蛋白运输路径、动植物差异、生物膜系统、高频易错点

## 操作

**桌面版**：鼠标拖拽环绕，滚轮缩放，单击查看，双击聚焦；进入漫游后用 `WASD` 移动、`Q/E` 升降、鼠标环视、`Esc` 退出。

**手机版**：单指旋转，双指缩放，轻点查看；进入漫游后用左下摇杆移动、拖动屏幕环视、右下按钮升降。

## 说明

- 单文件离线网页，Three.js 已内嵌，无需安装任何 3D 插件。
- 教学示意模型：细胞器大小、数量、位置经过艺术化处理，不按真实比例。
- 知识内容按人教版高中生物学必修1第3章整理，少量拓展内容已在文案中标注。
